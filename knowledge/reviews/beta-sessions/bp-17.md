## Interview focus, answered plainly

**Would a referral-based surgery practice run its day in this?** The front half, yes: the referral loop is on the queue row and the encounter card, the strip is ranked for surgery, and six taps file a note with charges and a claim. The back half is missing. There is no referral-back to Dr. Serrano when I file (records forwarded in, nothing forwarded out), no sedation record (agent, dose, times, vitals, escort), and no way to chart a visit-level code without a tooth. Curve had none of the first half and all of the tooth problem, so this is ahead, but not a surgery system yet.

**Which gates would slow a 12-minute extraction visit?** The read-back confirm is one tap and I accept it on a shared tablet. The tooth gate on D9243 is the one that costs me: a tap I should not need and a wrong tooth on the claim. Nothing else slowed me; the killer strip did not fire on a complete note.

**Does the record protect you in a Board complaint?** Frozen text, ruleset version, addenda-only and the author read-back are the right bones. What weakens it today is that the chart-derived line of the frozen note names only the last paint, so the D7210 I did is not in the note's own procedure line, and the sedation starter has no doses or times. A Board reviewer reads the note, not the ledger.
