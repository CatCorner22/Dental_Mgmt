## Summary

Third-party price ranges for 19 dental software products plus a negotiation guide built from 89 practitioner accounts (G2, Reddit, DentalTown). The clearest single table of estimates for quote-only vendors.

## Key concepts

- PMS estimates: DentiMax $100-$200; Open Dental $199 then $149; Practice-Web $149-$249; Adit $299-$399; Curve $299-$500 per location annual; tab32 $300-$500; Carestream $300-$500; Dentrix $400-$1,200 annual auto-renew; Eaglesoft $400-$600 + annual support; Denticon $400-$700; CareStack $698/user.
- Hidden costs: server $2,000-$5,000+ every 3-5 yrs; IT $100-$750+/mo; support renewal increases 8-12%/yr (Dentrix, Eaglesoft); comms add-ons $150-$400+/mo; conversion $800-$2,400; training $500-$2,000; ~$5,000 downtime; actual cost 1.5-3x sticker.
- Negotiation: start 60-90 days out; quarter-end leverage; ~1/3 of practices negotiated successfully; add-ons (training waivers, first-year discounts, bundles, 2-3-year price locks) move more than base price; ask for written data-export terms (CSV/XML/DICOM); use the Ascend migration push as leverage.
- Dentrix Enterprise is ONC-certified, so information-blocking rules apply to HS1 as a developer (dental applicability debated).
- Patient communication vendors: RevenueWell $189+, Weave $279-$349+, NexHealth ~$350, Solutionreach ~$400 (auto-renew, 15-day window).

## Notable quotes and data

- Negotiation guide says Curve 'starts at $249/user/month' while the pricing table says $299-$500 per location — internal inconsistency.
